# NYT Swiss Knife

Small tools beside the original NYT game controls. Independent project; not affiliated with The New York Times.

| Game | Tools |
| --- | --- |
| Connections | Fixed corner colors, category names, undo, difficulty and recorded tries. |
| Sudoku | Snyder and Center marks, erase, undo and configurable mode keys. |
| Strands | Draw paths and click or slide to erase them. |
| Wordle | Warn about conflicting letters and edit any active tile. |
| Crossword | Nearby clues, letter patterns, A–Z trials and a Pencil shortcut. |
