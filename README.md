# NYT Games Swiss Knife

Simple tools to make your NYT gameplay better

| Game | Tools |
| --- | --- |
| Connections | Colored corner marks, category names, undo/clear marks, one-click submission of every fully marked group in your chosen order (purple first by default), daily difficulty, and submitted tries. |
| Sudoku | Colored candidate: a second, italic candidate color (blue by default) with its own hotkey. Works with Auto candidate. |
| Crossword | Fast A–Z trials, Notes for candidate letters with erase/undo/clear, and configurable shortcuts. |
| Wordle | Warn about conflicting letters and edit any active tile. |
| Stats & calendar | Hard Sudoku and Daily Crossword times, speed colors, overall averages, daily edits, Chrome sync and JSON export. |

[Privacy policy](PRIVACY.md) · [Download releases](https://github.com/SHexagon-0x6/NYT-Swiss-Knife/releases)

Use the extension popup to open a game, see whether today’s puzzle is done, and turn each game’s tools on or off (games you turn off move to Archive). Use the Settings controls on a game page to choose individual tools. For controls and shortcuts, open **How to use** at the bottom of the popup.
